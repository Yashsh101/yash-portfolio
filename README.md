## Run locally

The portfolio is a zero-build static site with semantic HTML, a separate CSS system, and a small progressive-enhancement JavaScript layer:

```bash
python3 -m http.server 8000
```

Open `http://localhost:8000`. It works without JavaScript, respects `prefers-reduced-motion`, and is deployable to Vercel or GitHub Pages.
