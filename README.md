## Run locally

This portfolio is intentionally zero-dependency: a semantic `index.html`, a downloadable `Yash-Sharma.pdf`, and a small `styles.css` file. Open `index.html` directly or serve the directory with any static file server:

```bash
python3 -m http.server 8000
```

The site is designed for static hosting on Vercel or GitHub Pages.
